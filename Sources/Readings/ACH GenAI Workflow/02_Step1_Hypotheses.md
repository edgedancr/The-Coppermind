# Step 1 — Hypothesis Generation

## Objective

Frame the analytic question and produce a diverse, complete set of competing hypotheses. ACH only works if the true explanation is somewhere on the board.

## Prompt

```
The analytic question is:

[INSERT YOUR QUESTION HERE]

Generate a set of competing hypotheses that could explain this situation.

Requirements:
- Include at least 4 hypotheses. More is acceptable at this stage; we will consolidate later if needed.
- Include at least one hypothesis you would consider unlikely but still plausible. ACH fails if the correct answer is not represented.
- Include at least one hypothesis that challenges conventional assumptions, represents a contrarian view, or reflects an adversary's perspective.
- Include at least one hypothesis that involves deception — where the observable evidence has been deliberately shaped to mislead.
- For each hypothesis, provide:
  - A short label (e.g., "H1: State-Sponsored Attack")
  - A 2-3 sentence description of what this hypothesis claims
- Do NOT rank, evaluate, or express preference for any hypothesis. List them neutrally.

Checkpoint.
```

## Analyst Checkpoint

- **Coverage check:** Does the set of hypotheses span the realistic space of explanations? Think about who, what, why, and how — are there explanations you'd consider that aren't listed?
- **Devil's advocate check:** Is there at least one hypothesis that makes you uncomfortable or that you instinctively want to dismiss? If not, the set is probably too narrow.
- **Deception check:** Is there a hypothesis that accounts for deliberate manipulation of the evidence? In intelligence analysis, this is not optional.
- **Consolidation:** If two hypotheses are functionally identical (same actor, same motive, same method), merge them. If a hypothesis is truly impossible (not just unlikely), remove it.
- Tell the AI what to add, remove, or modify before proceeding.
