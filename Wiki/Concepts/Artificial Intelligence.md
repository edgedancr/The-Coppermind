SAIL approached artificial intelligence (AI) by asking what each word means. *Artificial* means created by man, implying imitation or the absence of naturalness: a human skill or craft made real. *Intelligent* means having the capacity to solve problems ([[SAIL Class Notes (Fall 2026)#9/8/26|SAIL notes, 9/8/26]]).

## Key Points
- **A broad definition** from Marc Andreessen: "The application of mathematics and software code to teach computers how to understand, synthesize, and generate knowledge in ways similar to how people do it... A way to make everything we care about better." ([[SAIL Class Notes (Fall 2026)#9/1/26|SAIL notes, 9/1/26]])
- **The progression:** statistics → machine learning → deep learning → reinforcement learning → generative AI → agentic AI ([[SAIL Class Notes (Fall 2026)#9/8/26|SAIL notes, 9/8/26]]). See [[Machine Learning]], [[Deep Learning]], and [[Agentic AI]].
- **Acts like a human, doesn't think like one:** see [[Intelligence vs. Consciousness]] ([[SAIL Class Notes (Fall 2026)#9/1/26|SAIL notes, 9/1/26]]).
- **By scope:** [[Narrow AI]] does a specific task really well ([[SAIL Class Notes (Fall 2026)#10/15/26|SAIL notes, 10/15/26]]); [[Artificial General Intelligence]] would do every human task better than every human ([[SAIL Class Notes (Fall 2026)#9/1/26|SAIL notes, 9/1/26]]).
- **Hard to measure:** traditional software gives objective data; AI gives subjective data ([[SAIL Class Notes (Fall 2026)#9/17/26|SAIL notes, 9/17/26]]). See [[LMSYS Chatbot Arena]].
