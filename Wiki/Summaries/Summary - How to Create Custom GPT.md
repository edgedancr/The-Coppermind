## Executive Summary
Kevin Stratvert's tutorial shows how to build a [[Custom GPT|custom GPT]], a version of ChatGPT specialized for one task, which requires a premium ChatGPT subscription.[^1] It builds a "Cookie Helper" for a cookie company, first by conversing with the GPT Builder and then by editing its settings by hand,[^2],[^3],[^4].[^5] It tests the GPT, uploads a recipe file so it can answer about the company's own cookie, and adds a formatting example to its instructions,[^6],[^7].[^8] It then covers optional capabilities, actions that call outside APIs, a setting for sharing conversation data with OpenAI, and publishing options,[^9],[^10],[^11].[^12] The tutorial states no thesis; its central argument is that custom GPTs save time on repeated, specialized tasks [inferred].[^13]

## Main Points
- A GPT focused on one task should give more accurate results.[^14]
- Building is iterative: preview, adjust the instructions, and try again.[^8]
- Uploaded files let the GPT answer what it didn't know.[^7]
- Actions make the GPT a conversational layer over outside APIs.[^10]

## Themes
- [inferred] Specializing a model through instructions and files rather than through training.
- Trial and error as part of building.

## Key Takeaways
- Explicit: build a custom GPT for tasks you repeat, such as one per class with its textbook uploaded.[^13]
