## Executive Summary
Kevin Stratvert's tutorial shows how to build a [[Custom GPT|custom GPT]], a version of ChatGPT specialized for one task, which requires a premium ChatGPT subscription ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 1]]). It builds a "Cookie Helper" for a cookie company, first by conversing with the GPT Builder and then by editing its settings by hand ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 3]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 4]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 6]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 7]]). It tests the GPT, uploads a recipe file so it can answer about the company's own cookie, and adds a formatting example to its instructions ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 8]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 9]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 10]]). It then covers optional capabilities, actions that call outside APIs, a setting for sharing conversation data with OpenAI, and publishing options ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 11]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 12]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 13]]), ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 14]]). The tutorial states no thesis; its central argument is that custom GPTs save time on repeated, specialized tasks [inferred] ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 15]]).

## Main Points
- A GPT focused on one task should give more accurate results ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 2]]).
- Building is iterative: preview, adjust the instructions, and try again ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 10]]).
- Uploaded files let the GPT answer what it didn't know ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 9]]).
- Actions make the GPT a conversational layer over outside APIs ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 12]]).

## Themes
- [inferred] Specializing a model through instructions and files rather than through training.
- Trial and error as part of building.

## Key Takeaways
- Explicit: build a custom GPT for tasks you repeat, such as one per class with its textbook uploaded ([[Kevin Stratvert - How to Create a Custom GPT (transcript)|Stratvert, custom GPT, ch. 15]]).
