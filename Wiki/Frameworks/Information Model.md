> [!summary]
> Intro to Intelligence's Information Model describes five levels that raw signals pass through on the way to becoming intelligence: signal, data, information, knowledge, and wisdom or intelligence ([[Intro to Intelligence Class Notes (Fall 2026)#8/25/26|Intro notes, 8/25/26]]). The course taught that context is what moves information up the levels ([[Intro to Intelligence Class Notes (Fall 2026)#8/27/26|Intro notes, 8/27/26]]).

## Components
| Level | Description |
|---|---|
| Wisdom / intelligence | Predictive insight; time-sensitive knowledge; intelligence products |
| Knowledge | Information in context or comparison; analyzed information (models or other structure to draw out meaning) |
| Information | Data processed into humanly "readable" form; collated or aggregated data |
| Data | Signals in machine-readable form (analog or digital) |
| Signal | Electrons (radio frequency), photons (light), other communications |

Source for the table: ([[Intro to Intelligence Class Notes (Fall 2026)#8/25/26|Intro notes, 8/25/26]])

## How to Use It
- **Context is the engine.** The course taught that context "could be asserted to be everything for an intelligence officer": ==it is the most important thing in transforming raw data points into knowledge, wisdom, and intelligence== ([[Intro to Intelligence Class Notes (Fall 2026)#8/27/26|Intro notes, 8/27/26]]).
	- "Every bit of information can mean something" ([[Intro to Intelligence Class Notes (Fall 2026)#8/27/26|Intro notes, 8/27/26]]).
	- History matters because it supplies context ([[Intro to Intelligence Class Notes (Fall 2026)#8/27/26|Intro notes, 8/27/26]]).
- The same "dots" can have completely different implications depending on their context ([[Intro to Intelligence Class Notes (Fall 2026)#9/8/26|Intro notes, 9/8/26]]). See [[Puzzles and Mysteries]].
- For the process that moves collected material through these levels, see [[Tasking, Collection, Processing, Exploitation, and Dissemination]].
