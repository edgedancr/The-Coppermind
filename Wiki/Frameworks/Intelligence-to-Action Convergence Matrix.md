> [!summary]
> The Intelligence-to-Action Convergence Matrix lines up four models of how information becomes action (the ISR pipeline, the intelligence cycle, the OODA loop, and the kill chain) against one common set of stages, from tasking to assessment ([[SAIL Class Notes (Fall 2026)#10/20/26|SAIL notes, 10/20/26]]). Read as a table, it shows where each model's steps correspond.

## Components

| Model | Tasking | Collection | Processing | Exploitation | Dissemination | Decision | Action | Assessment |
|---|---|---|---|---|---|---|---|---|
| ISR pipeline | Task | Collect | Process | Exploit | Disseminate | | | |
| Intelligence cycle | | Collect | Process | Analyze | | Decide | Act | |
| [[OODA Loop]] | | Observe | Orient | | | Decide | Act | |
| [[Kill Chain]] | | Find and fix | Track | | | Target | Engage | Assess |

> [!caution] Sources disagree
> SAIL's intelligence-cycle row runs collect, process, analyze, decide, act (SAIL notes, 10/20/26). Intro to Intelligence taught the intelligence cycle as collection, processing, analysis and production, and dissemination (Intro notes, 9/15/26). See [[Intelligence Cycle]].

- The ISR pipeline row uses the same five stages Intro to Intelligence taught as TCPED ([[Intro to Intelligence Class Notes (Fall 2026)#9/1/26|Intro notes, 9/1/26]]); see [[Tasking, Collection, Processing, Exploitation, and Dissemination]].

## How to Use It
- Read down a column to see how the same stage appears in each model. For example, "Decide" in the intelligence cycle and OODA loop lines up with "Target" in the kill chain.
- Pair it with [[Human Decision Point]]: SAIL places AI in the collection and processing stages and humans in deciding and acting ([[SAIL Class Notes (Fall 2026)#10/20/26|SAIL notes, 10/20/26]]).
