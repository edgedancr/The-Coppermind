Search the Coppermind without AI or an internet connection. Everything on this page uses Obsidian's own search, so it works offline. Click any link below to run that search.

## Three ways to look something up

| I want to…                                             | Do this                                                                                       |
| ------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Open a page when I know its name                       | `Ctrl+O`, then type the title **or an alias** (try `ACH`, `TCPED`, `EO 12333`, `CNE`, `LOAC`) |
| Find every page that mentions a word or phrase         | `Ctrl+Shift+F`, then type it. Use quotes for an exact phrase: `"proximate reality"`           |
| Browse or filter every page by type, course, or status | Open the [[Library.base]]                                                                     |

## Search tips

| Type this | To find |
|---|---|
| `"exact phrase"` | that exact wording |
| `word1 -word2` | pages with word1 but not word2 |
| `file:kill` | pages whose *title* contains "kill" |
| `path:"Wiki/Frameworks"` | pages in one folder |
| `[type:framework]` | pages with that property value |
| `[courses:SAIL] [status:draft]` | both conditions at once |
| `line:(hallucination fluent)` | both words in the same line |
| `section:(Key Points hallucination)` | the word under a "Key Points" heading |
| `/Top Secret\|TS/` | a regular expression |

> [!info] If a one-click link doesn't run
> The links open Obsidian's search for a vault named **The Coppermind**. If your vault has a different name, use `Ctrl+Shift+F` and type the search from the tables above instead.
