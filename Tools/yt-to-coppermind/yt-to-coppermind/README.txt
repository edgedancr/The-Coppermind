YouTube to Coppermind (v1.1)
1. Unzip this folder somewhere permanent.
2. Chrome > chrome://extensions > turn on Developer mode > Load unpacked > pick this folder.
   (If updating: click the reload arrow on the extension instead.)
3. Click the puzzle-piece icon in Chrome's toolbar and pin the extension.
4. On a YouTube video, click the extension icon. The badge shows ... then a green check when the file is in Downloads,
   or a red ! (hover the icon to read the message).
5. Move "<Channel> - <Title> (transcript).md" from Downloads to Sources/Readings/.
If YouTube changes its page and it breaks, the selectors are in format.js under CM.SEL.
