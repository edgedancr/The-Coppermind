The changelog of [[Nicrosil]], newest first. It lives here in `_changelogs/`, outside the guide, so an agent reading the guide doesn't also read all of this. Read it only to add a line for a new version or to look up when something changed. Past lines are never rewritten; a correction goes in a new line. How something looks (corners, fonts, colors, animations) belongs in these lines, not in the guide's body.

- **2.13.2:** The Dashboard's search bar has the same outline as the other gradient boxes: sharp 2px corners (it was a pill), a copper-to-teal gradient line on a dark fill, and a soft glow that brightens on hover and when you click into it. What you type and the placeholder use the serif (Georgia) that the Dashboard's link-card titles use, at the same size. CSS only; the results list is unchanged.
- **2.13.1:** Pointing at (or tabbing to) a page card in the relations map, in the panel or the Enlarge window, lights up that page's relationship names in the legend under the map: a sharp 2px outline and a soft glow in each relationship's own color, with the text brightened. It clears when the pointer leaves. Legend chips also have a little padding now.
- **2.13.0:** The relations map has an **Enlarge** button under it on every page, replacing the Show all button that only appeared on crowded pages. It opens the map in a wide window (up to 920px) with every page, so the map is bigger as well as complete; the window scrolls when there are many pages, and clicking a page there opens it and closes the window. The map in the panel still shows up to six pages on each side, with a note when there are more.
- **2.12.1:** The relations map's **Show all** button now appears when a page has more than six pages on a side, not ten, and the map starts with six on each side. Nothing else changed.
- **2.12.0:** The relations map is no longer capped at ten pages a side. When a page has more than ten on either side, a **Show all** button under the map (the same gradient button as Open next draft) draws every page and makes the map taller; **Show fewer** puts it back to ten. It resets to ten when you open another page. The note inside the map now says how many more there are and points to the button. Nothing changes for pages with ten or fewer.
- **2.11.3:** The relations panel's map box has the same outline as the Open next draft buttons: sharp 2px corners and a copper-to-teal gradient line with a soft glow in both colors, in place of the plain copper line. The fill, the pages and the arrows inside it are unchanged. CSS only.
- **2.11.2:** A new month's log file no longer starts with a `# Log` title, which only repeated the file name Obsidian already shows. Existing month files, `_index.md` and `Triage.md` had the same kind of title removed by hand.
- **2.11.1:** Both **Open next draft** buttons (the Dashboard's review progress card and the review panel) now match the other gradient buttons: sharp 2px corners, a copper-to-teal gradient outline on a dark fill, and a soft glow that brightens on hover. When the queue is empty the button is dimmed with no glow. CSS and one class name only; nothing else changed.
- **2.11.0:** The Dashboard has four link cards instead of six: the **Review queue** and **Guides** cards are gone, which moves the review progress up. The first review progress card has an **Open next draft** button, which replaces the unseen Start reviewing button and opens the next draft in the queue (and shows the review queue on the right). `Ctrl+click` opens the draft in a new tab. The review queue is still on `Alt+Q`, the ribbon button and the status bar.
- **2.10.0:** The log is one file per month in `_logs/`, named `_log MM-YY` (`_log 11-26` is November 2026). Verify, Reject and the Home rename add their entry to the top of the current month's file. When Obsidian opens in a new month, or an entry is added in one, Nicrosil creates that month's file with its header (it no longer moves old entries into a `Logs/` folder). The Dashboard's **Log** card opens the newest month's file, and the recent-activity list reads the newest file and carries on into earlier ones until it has six entries. Every month's file folds its entries and hides its properties.
- **2.9.0:** The index and the log are now `_index.md` and `_log.md`, so Nicrosil reads and writes them there: verify and reject update the index and add their log entry, the properties are hidden on both, the Dashboard's activity list and its Index and Log cards open them, and the log still folds and moves finished months to `Logs/`. The Dashboard's **Log** and **Wiki map** cards swapped places, so the order is Index, Review queue, Log, Wiki map, Schema, Guides.
- **2.8.4:** The Dashboard's tab says "Dashboard" instead of showing the logo, at the normal tab width (it replaces the narrow logo tab of 2.8.1 and 2.8.2). The path above the page is still hidden. The hover label still says `_dashboard`.
- **2.8.3:** `Ctrl+click` (or `Cmd+click`) on a page in the review queue opens it in a new tab: the rows in the queue and the Verified list, and **Open next draft**. The Dashboard's **Start reviewing**, its changed-page rows and its page links do the same. A plain click behaves as before.
- **2.8.2:** The Dashboard's tab was too narrow to show anything. It is now a fixed 72px wide, with the logo on the left and the close button on the right, and the logo is drawn in its own box so the tab's text rules can't clip it.
- **2.8.1:** The Dashboard no longer shows its file name. The path above the page (`_dashboard`) is hidden, and the Dashboard's tab shows only the copper logo and the close button, in a narrow tab instead of a full-width one. The tab is marked with a `cm-dashboard-tab` class by the same code that marks the page; the hover label still says `_dashboard`.
- **2.8.0:** The Dashboard is now the file `_dashboard.md` (renamed from `Dashboard.md`; the underscore keeps it out of the file list unless the eye button is on). Nicrosil finds it by that name: the Coppermind button, `Alt+D`, the Dashboard styling and Reading view all follow it. The old names `Dashboard.md` and `Home.md` are still recognised. At startup Nicrosil also points the Homepage plugin's setting at the new name, if that plugin is installed. The health-check script also ignores links from the new name when it looks for orphan pages.
- **2.7.9:** The eye button hides files whose names start with an underscore too, not only folders (`_Dashboard.md`, say). A file inside a folder with an underscore was already hidden with it. The button's tooltip says "files and folders".
- **2.7.8:** The log is newest first. New entries from Verify, Reject and the Home rename go at the top of `log.md`, under its header. A month moved into `Logs/` keeps its order, and joins an existing month file at the top. The Dashboard's recent activity reads from the top of the log, and a new month file says "Newest at the top". The **Log a schema change** dialog now says its line is added to the top of the changelog (it still said bottom).
- **2.7.7:** The **Log a schema change** button puts the new line at the top of the Schema Changelog, which is now newest first, instead of at the end. Which version counts as the latest is unchanged (it is the highest, not the last).
- **2.7.6:** The **Ambient animations** setting is gone. The glowing titles, breathing flag callouts, map sparkles, page fade and drifting background are always on, and still stop if the computer is set to reduce motion. The page fade-in is fixed: it used to start after the page had loaded and been drawn, so the page showed and then faded. A page's text is now held back while the file loads and fades in as soon as it is ready, in 0.2 seconds with no upward movement, and the background no longer fades with it.
- **2.7.5:** An eye button in the file list's toolbar, after collapse-all, shows or hides every folder whose name starts with an underscore (`_attachments`, `_changelogs`, `_templates`). They are hidden each time Obsidian opens, and the choice is not remembered. The button is filled in while they are shown.
- **2.7.4:** The **Log a schema change** button finds the Schema Changelog in its new folder, `_changelogs/` (it moved out of `SCHEMAS/`). The button still shows on every page in `SCHEMAS/`.
- **2.7.3:** The relations panel's map matches the wiki map: sharp 2px corners on the boxes, the map frame and the status tag; flat dark fills; no dotted backdrop, flowing dots, pulsing halo, entrance animation or hover growth; thinner arrows; the page title is in the same serif as the Review queue header. The Review queue header and the relations panel title are a still copper-to-teal gradient with a soft glow, like the Dashboard's name; the queue header no longer shimmers. The open page in the middle has a thin copper-to-teal gradient outline with a faint glow, like the file-list button. Only the look changed, not what the map shows.
- **2.7.2:** Rejecting a page rewrites [[_index]] and now keeps its new layout: the A–Z letter headings in Concepts and Glossary are rebuilt in place, and the **Jump to** line gets the new counts. Without this, the letter headings would have been pushed to the bottom of their section.
- **2.7.1:** The name on the file-list button is larger. It was capped by a conservative width estimate and left empty space; it now scales to fill the button (up to about 1.7em, down to 0.7em in a very narrow file list).
- **2.7.0:** The wiki map and the hierarchy look less glossy: sharp 2px corners on cards, buttons, menus, chips, the info card and the frames; no glows or hover growth; thinner lines; no dotted backdrop or lights running along the hierarchy's branches; the map's drifting sparks are gone; the active tab uses the copper-to-teal gradient; the info card's name is in Almendra SC.
- **2.6.3:** The Dashboard name's copper-to-teal gradient now spans the width of the name itself instead of the whole header, so the teal end shows and it matches the file-list button.
- **2.6.2:** The Coppermind name on the Dashboard and on the file-list button is set in **Almendra SC**. The Dashboard name has a copper-to-teal gradient and a soft glow. The font loads from Google Fonts, so it needs an internet connection; offline it falls back to Georgia.
- **2.6.1:** The **The Coppermind** button at the top of the file list has a copper-to-teal gradient fill and border, the name fades from copper to teal, and its corners are sharp (2px). Hover glows in both colors.
- **2.6.0:** The rules moved to `SCHEMAS/`: the rule files are reviewable (grouped as **Schemas** in the queue), the pen button shows on every page there, and **Log a schema change** writes to [[Schema Changelog]] and keeps the version in [[SCHEMA]]. The log is split by month: finished months move to `Logs/Log YYYY-MM.md`, month files open folded, and Recent activity fills from last month early in a month. Log entries with the new `tool` operation get a hammer icon. Once, at startup, the old root `SCHEMA.md` (left as a "moved" stub) goes to the trash.
- **2.5.3:** The Dashboard button moved from the left ribbon to a large **The Coppermind** button, with the logo, at the top of the file list. Click opens the Dashboard; `Ctrl+click` or middle-click opens it in a new tab. The ribbon logo is gone.
- **2.5.2:** The pop-up preview of a linked page shows the one-line properties strip (type, status, date) instead of the full Properties block, like an open page. Click the strip in the preview to open the real block.
- **2.5.1:** The wiki map is plain again: no halos around the dots, no breathing, no fade-in, and no dotted backdrop, only a soft copper edge and glow on the frame. The dropdown menus keep their arrows. The hierarchy keeps its glow.
- **2.5.0:** The wiki map and the hierarchy look like the relations panel: a dotted backdrop with a copper glow, glowing borders and buttons, lit dots with halos, cards with teal or copper glow, glowing branches with lights flowing from parent to child, and a fade-in when they open. The info card and the buttons, menus and relationship chips are restyled to match.
- **2.4.9:** A line in a page's **Changed since verified** list is a link when it ends with `[[#Heading]]`: clicking it, on the review card or the Dashboard, goes to that section of the page. A line with no location still opens the page.
- **2.4.8:** The Dashboard has a health check card: a bar that fills over the 14 days since the last report in `Health Checks/`, amber when the next check is due within two days and red when it is overdue. New setting **Days between health checks**.
- **2.4.7:** New setting **Open pages in Reading view**: verified pages (or every page, or none) open in Reading view instead of editing, and stay in editing if I switch them there myself.
- **2.4.6:** The relations map is livelier: glowing arrows with dots flowing along them, a pulsing center page, a dotted copper-lit backdrop, nodes that fade in, and a hover highlight that lights a page's arrows and dims the rest.
- **2.4.5:** Search snippets and review-card summaries leave out footnote markers (`[^1]`) and the Footnotes section, after citations moved to footnotes (Schema §6).
- **2.4.4:** The verify animation's check is a copper-to-teal gradient, with no orb behind it.
- **2.4.3:** Made some small visual improvements to the review queue panel.
- **2.4.2:** The Dashboard always uses the quiet style; the Classic/Quiet setting is gone. The open file in the file list has a soft copper-to-teal highlight and a teal-to-pale-copper name instead of flat orange and teal.
- **2.4.1:** The Dashboard's six links are small, sharp-cornered cards again, and Review progress is a card with larger text and a glowing copper-to-teal bar.
- **2.4.0:** A quieter Dashboard: plain header without a panel or sparks, links without icons or per-card colors, the stat tiles and ring replaced by one line of stats, and small serif capitals for headings. Also since 2.3.0: the verify animation lifts the page up and the next one rises from the bottom, both sidebars share the background glow, and the open file's name in the file list is teal.
- **2.3.0:** Removed the 14-day activity chart from the Dashboard; the Verification card is now full width with a larger ring and larger text.
- **2.2.1:** Fixed the verify animation: the page slides away and the next one slides in again (the background drift had been overriding it). Removed the sparks from opening a page, leaving only a short fade.
- **2.2.0:** Review queue: the progress bar is sharper with a steady glow (no pulse or sheen), and the draft list is a set of cards with a colored edge (amber for flags, rust for changed since verified, teal for the current page) and the page type under each name.
- **2.1.0:** The page-open transition is sparks only (no light sweep), with more sparks that rise higher. A new setting closes the Backlinks, Outgoing links, Tags, All properties and Outline panels at startup.
- **2.0.0:** Page-open transition (copper light sweep and rising sparks), a larger glowing progress bar and a gradient title in the review queue. Removed the Dashboard spotlight, the amber pulse on the map, and the relations-panel line animation. Fixed two animation names that clashed with the Dashboard hero.
- **1.6.0:** Ambience: title auras, breathing flag callouts, map sparks, ripples and amber pulses, relations lines that draw in, Dashboard spotlight and milestone bursts, queue and search touches, page fade-ins, and a slow background drift. A new setting turns them off.
- **1.5.0:** Verifying a page plays an animation: a check stamp and spark burst, the page slides away, and the next page slides in. A new setting turns it off.
- **1.4.1:** Dashboard fixes: the verification ring's filled part is drawn again, shading from copper to green; the three stat tiles glow only when pointed at; and the six navigation cards have a colored outline all the way around.
- **1.4.0:** The copper-and-teal gradient background now applies to every note, not just the Dashboard.
- **1.3.2:** The Dashboard background is a stronger copper-to-teal gradient over the brown, defined as the reusable variable `--cm-bg-gradient`.
- **1.3.1:** The Dashboard goes back to the vault's brown background, so moving to another page is less jarring. Cards and the header are re-tinted brown to match.
- **1.3.0:** Dashboard redesign: copper and teal accents (first with a slate background, replaced in 1.3.1), gradient-edged cards, colored navigation icons, a header with drifting sparks and the search box inside it, a verification ring, a 14-day activity chart, per-type bars, and entrance animations. The separate search block was removed from the Dashboard page.
- **1.2.1:** The wiki map always opens on the Map tab instead of remembering the last tab used.
- **1.2.0:** The Hierarchy view is now a branching diagram of cards joined by curved colored lines, with open/close circles, hover highlighting of a page's path, and drag to pan. Fixed the filter box, which did not update the diagram as you typed.
- **1.1.0:** The wiki map is alive: dots settle with physics and can be dragged, pointing at a dot highlights its links, the view glides to a focused page, arrows are curved with a soft glow on verified pages, and a pulse flows along each link (with a **Flow** switch).
- **1.0.1:** The wiki map's relationship chips no longer show a count after each name.
- **1.0.0:** The wiki map moved from the left ribbon to a Dashboard card, replacing the My Worldview card (`Alt+M` still works).
- **0.10.0:** New wiki map (`Alt+M`) with a hierarchy tree and a zoomable map of all typed links.
- **0.9.2:** The Dashboard search box no longer stops at 8 results. It ranks every match and draws 20 cards at a time, loading more as the list is scrolled or the arrow keys go past the end, with a running count at the bottom.
- **0.9.1:** The Dashboard's "Changed since verified" section is always collapsed when the Dashboard opens or refreshes.
- **0.9.0:** New relations panel (`Alt+L`): a map and grouped lists of the open page's typed links, both outgoing and incoming.
- **0.8.11:** Verified pages the AI changed at my request carry a `changes_since_verified` note. Verify deletes it; the queue lists these pages first with an **R** badge; the review card and the Dashboard show the notes.
- **0.8.10:** Middle-clicking the Dashboard logo now opens exactly one new tab and leaves the current tab alone. Obsidian was sending the middle-click to the logo's click handler more than once, so the plugin now counts one middle-button press as one open.
- **0.8.9:** Fixed middle-click on the Dashboard logo also loading the Dashboard into the current tab. It now opens one new tab and leaves the current tab alone.
- **0.8.8:** Middle-click or Ctrl+click on the Dashboard logo now opens a new tab even when the Dashboard is already open; before, it just switched to the open tab.
- **0.8.7:** Middle-clicking the Dashboard logo in the ribbon opens the Dashboard in a new tab.
- **0.8.6:** The index no longer splits each type into Verified and Drafts. It is one alphabetical list per type with a single total, and verifying a page no longer changes the index. A page's status is shown by the review queue, the Dashboard, and the page's own properties strip.
- **0.8.5:** The Dashboard's six navigation cards open in a new tab on `Ctrl+click` or middle-click. The plugin's id and folder changed from `coppermind-review` to `nicrosil`. The guide became a guide to the whole plugin, not only the review buttons.
- **0.8.4 and earlier:** Review queue, flags, hotkeys, Dashboard blocks, search, the properties strip, log folding, and the schema-change button. See the dated entries in [[_log 11-26]] for each step.
