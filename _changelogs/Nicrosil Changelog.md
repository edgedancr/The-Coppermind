The changelog of [[Nicrosil]], newest first. It lives here in `_changelogs/`, outside the guide, so an agent reading the guide doesn't also read all of this. Read it only to add a line for a new version or to look up when something changed. Past lines are never rewritten; a correction goes in a new line. How something looks belongs in these lines, in a few words, not in the guide's body. From 4.3.5 on, each line is at most two sentences and covers one session's changes; code details are in git ([[SCHEMA - Changes#Nicrosil and other tools]]).

- **4.11.0:** The Connections map on each page now groups linked pages by link type, showing each group's busiest pages with a **+ more** toggle for the rest, and joins every group to the open page with a band as thick as the group. The legend, zoom and pan are gone.
- **4.10.1:** The Atlas now has the Dashboard's drifting copper-and-teal gradient background, with clear topic circles, sharp gradient lines for circles and bands, small-capital topic names and flat page dots with ringed anchors, all glowing only when you point at them. Its side panel is now open, with no background of its own, and tracked-caps section headings. It turns lilac in Tinmind mode.
- **4.10.0:** Every note page in the Tinmind now has a **Send to Raw** button (an inbox icon) in its tab header that copies the note, unchanged, into Ingestion/Raw. The note stays where it is, an existing file in Raw is never overwritten, and course pages, the Notebook page, the Dashboard and All Class Notes don't get the button.
- **4.9.2:** The Lens is removed. Its sidebar view, its tab-bar button, its **Enlarge** window and its trail are gone, and a Lens tab left in a saved layout closes at startup; **Connections** on each page is what is left, and `Alt+L` opens or folds it. The map and lists it needed moved into Connections' own code; `07-lens-view.js` is now empty and can be deleted.
- **4.9.1:** The Connections map no longer has an **Enlarge** button. It fills the page's width, shows every page it links with (not six a side), and zooms and pans: **Ctrl + scroll** (or a trackpad pinch) zooms at the pointer, a drag pans, the **+**, **-** and fit buttons in its corner zoom and reset, and double-clicking the background shows the whole map again. Plain scrolling still scrolls the page.
- **4.9.0:** The Lens is now a folding **Connections** section at the bottom of each wiki page, perspective and source card, just above the Footnotes heading (or at the end of a page without one), in Reading view and Live Preview. Folded, it shows the link counts and the page's two biggest typed-link groups; open, the map with **Enlarge**, then folded lists of pages two steps away, the pages it links to and the pages linking to it. `Alt+L` opens or folds it on every page, and a setting turns it off. The Lens sidebar and its tab-bar button are gone, and with them the trail.
- **4.8.0:** Each ingest tab now lists the typed links Claude added, marked stated or inferred and whether they reset a verified page; **Remove** takes one out and logs it as rejected with my reason. The Lens, atlas and **Add typed link** know the new `threatens`, `requires` and `summarizes` types.
- **4.7.0:** Ingests now move the source from Ingestion/Raw into Sources/ under a new name, and approving a plan makes the verified-page changes I left ticked (an unmade one is flagged in the tab). The usage meter now checks Anthropic only at startup, after a run, and while its Usage popup is open, so it stops being rate-limited.
- **4.6.3:** The usage meter is now a small **Usage** button in the other places too, so none of them show it all the time: to the right of **Depth** in Query mode, above the Ingest buttons in Triage, and after the chips on each ingest tab. Click it and the meter opens; a click elsewhere or Escape closes it. It replaces the always-visible meter from 4.5.0.
- **4.6.2:** The usage meter in the transcription queue is now a small **Usage** button next to **Transcribe**: the meter opens above it when I click, and closes on a click elsewhere or Escape. It replaces the always-visible meter from 4.6.1, which crowded the tray.
- **4.6.1:** The transcription queue's tray now shows the live usage meter above the **Transcribe** button, in the Tinmind's grey-to-lilac TGS instead of the copper-to-teal CGS, so I can see my limits before sending scans to Claude.
- **4.6.0:** The transcription queue now has a **Transcribe scans** button: I tick the scans from one class session, pick a course, model and effort, and Claude Code drafts the note, which then waits in the queue like any other draft. Claude can also recreate a drawing or re-read unsure words from their cards, and new phone photos can be shrunk into Sources/Scans first with the shrink tool.
- **4.5.0:** The usage meter under the Dashboard's query bar is now live, and the same meter shows beside the Ingest button in Triage and under the title on each ingest tab: it shows the 5-hour and 7-day limits with when each resets, checks when Obsidian starts, every 30 seconds, and every 10 seconds while Claude Code runs, and can be turned off in Settings. To do this it reads Claude Code's saved sign-in, which goes only to Anthropic.
- **4.4.1:** The usage meter under the Dashboard's query bar now shows your plan usage as a percent, using the limit window closest to full. Before, it only showed the last query's token count.
- **4.4.0:** The Triage card now opens a Triage dashboard that lists every source in Ingestion/Raw as it arrives, marks which need a text copy, and ingests the ones I pick through Claude Code with a model, effort and mode I choose. Each source gets its own ingest tab, where a plan shows as a board of drafts to tick and questions to answer, and the right sidebar closes while Triage is in front and opens again when I leave.

- **3.30.3:** The atlas is faster to pan, zoom and click around in once a topic is open. Measured in a browser (software drawing, so only the comparison counts): the slowest part was redrawing the dashed "see" links, and the rest was a handful of smaller costs. (1) The view is now drawn once a frame (`queueVb`) however many wheel or drag events arrive, the size of the svg is measured once (`svgRect()`, cleared when the space changes) and not on every move, and `--k` is only rewritten when the zoom actually changes, so a pan restyles nothing. (2) While the view moves (a drag, the wheel, a glide), `is-moving` draws the dashed links solid; they are dashed again 180 ms after it stops. (3) A topic's links are drawn as a few paths, one for each kind and type of link, not one path each (333 elements became 7 for the biggest topic); a traced page's links stay separate because of their arrowheads. (4) `vector-effect: non-scaling-stroke` is gone: line widths and dashes are `calc(N px * var(--k))` instead, so they look the same. (5) Dimmed topics use `fill-opacity` and a dimmer name color, not whole-group opacity; the fade on the dots is removed, so dimming is instant. (6) The dots and topic circles don't take the pointer while the view is dragged, so no hover is worked out as they pass under it. In the browser test the frame time while panning went from 33 ms at worst to a steady 16.7 ms, and zooming from stalls of 150 ms to a steady 16.7 ms. Not yet seen in Obsidian.

- **3.30.1:** The atlas fits itself to the space it has. Opening it closes the sidebars (3.30.0), which widened the stage after the view had been fitted to the narrower one, so the map sat small in the middle. `fitBox()` is now the one place that works out the view (the traced page and its neighbors, the open topic, or the whole wiki, at the stage's current shape; `apply()` uses it), and `refit()` runs it again, after the resizing settles (140 ms), whenever the stage's width changes (a `ResizeObserver` on `.cm-at-stage`, and the view's `onResize`): it works out the whole-wiki box again (topic names take more room on a narrow stage) and glides to the new fit with the same 380 ms ease as a click, unless `userView` is set (the wheel or a drag sets it; picking a topic, a page or the title clears it), in which case the zoom stays where I put it. The first time the atlas draws it starts at 1.5 times the fitted width and eases in to the fit (not under reduced motion); a redraw after a link change doesn't repeat it. `onResize` no longer redraws or snaps. Not yet seen in Obsidian.

- **3.29.0:** The wiki map is the atlas and the relations panel is the Lens (option A, the topic atlas, and option B, the neighborhood lens, from the map mockups). **Atlas** (`WikiMapView`, same view type `nicrosil-wikimap`, tab name "Atlas"): reads the new vault file `_topics.md` (`TOPICS_PATH`; `parseTopics`: each `## ` heading is a topic, the first plain line under it its description, the `[[links]]` in its list items its anchors) and every link between pages in `Wiki/` and `Perspectives/` (`collectLinks`: the typed links from `collectRelations`, plus a `see` link for every other pair in `metadataCache.resolvedLinks` that no typed link joins in that direction). `assignTopics` runs a random walk with restart (restart 0.25, 40 rounds) from each topic's anchors over the undirected links (typed weight 2, plain 1) and puts each page with the topic that reaches it most strongly, divided by the page's own link weight; anchors are pinned (a page listed twice stays in the first topic); pages no topic reaches go in a "No topic yet" group. `layoutAtlas` places the topic circles (radius 26 + 21·√pages) with a short fixed-step force pass (start on a ring in file order, linked topics pulled together, squashed gravity and a final stretch toward a 1.7 width-to-height shape, 58 units between circles for the names) and the dots inside each circle (repulsion, springs along links, anchors pulled to the middle, pages with links to other topics pulled toward their side of the rim), all with seeded starts (`hash01`), so the same links give the same picture. The plugin's `atlas()` keeps the result in `atlasCache`, keyed on the topic list, the page paths and every link; a change that leaves the key alone only recolors (statuses and types), so typing in a page doesn't redraw the map or lose the zoom. Drawn as SVG, worked out once, with no simulation and no animated arrows: bands between circles (rim to rim, bowed 8%, width 1.2 + 1.5·√links, capped at 16, copper at 24%, amber when the open topic's), circles with a soft copper radial fill (`#cm-at-fill`; grey and dashed for No topic yet), topic names above them in Almendra SC filled with a copper-to-teal SVG gradient (`#cm-at-tgrad`, the CGS colors) with a dark halo, wrapped to two lines past 18 letters (`wrapWords`), and dots sized 3.2 + 1.5·√(links in), capped at +8, colored by status (verified `#5fae9e`, re-review `#ecb54e`, draft `#a65f2b`) or by page type, anchors with a pale ring. Text and line widths stay their size on screen at every zoom (`vector-effect: non-scaling-stroke`, and font sizes times `--k`, the SVG units per pixel). Clicking a topic glides the viewBox to it (380 ms ease, none under reduced motion), draws its links (inside at 38%, to other topics at 14%, plain links dashed) and names its anchors and 14 busiest pages; clicking a dot traces it (its links with arrowheads in their type's colors, everything else at 15%, names on it and its neighbors, or on its typed neighbors and ten busiest when it has more than 22) and zooms to fit them. Wheel zoom around the pointer, drag to pan (a click after a drag is ignored), `Esc` and the path at the top step back, a click on empty space returns to the whole wiki. The bar: the "Atlas" title in CGS, the path, a search box with up to eight matches (arrow keys, Enter), **Status**/**Type**, **Edit topics** (creates `_topics.md` with a short intro if missing, and opens it in a new tab). The side panel (300px, `--background-secondary`) shows the whole wiki's counts, a status bar and the topics; a topic's description, counts, status bar, anchors, eight most-linked pages, six most-linked topics, topics with no links, and up to six pages whose next topic scores at least 75% of theirs; a page's type, status, topic (with "also close to" past 20%), **Open page** and its links by type as chips (24 a type, then "+n more"). A missing `_topics.md` and anchors that aren't pages are reported in the panel. `onResize` refits a map drawn while its tab was hidden. Gone: the Hierarchy tree and the force-directed Map (`buildWikiGraph`, `seedPositions`, `stepSim`, `SIM`, `addPageGradients`, `renderTree`, `drawTreeRows`, `renderMap`, `drawInfo`), the `mapTab` and `mapFlow` settings (deleted on load), and every `.cm-wm-*` and `.cm-wt-*` rule but `.cm-wm-legend`, which the Dashboard's status key uses; the new rules are `.cm-at-*`. **Lens** (`RelationsView`, same view type, tab name "Lens"): plain links join the typed ones (`LINK_TYPES` adds `see`: "Links to"/"Linked from", `#8c8174`, dashed 3 3), only between wiki pages, perspectives and source cards (`inLinkScope`), so the index, logs and rule files no longer count; neighbors are sorted typed first, then by links in; a re-review state (`pageState`: a draft with `changes_since_verified`) gets amber boxes, dots and badge; the header gains the page's topic as a teal outlined chip that opens the atlas on the page; a "Trail" row of up to five pages opened before this one; "Two steps away, not linked yet" (`suggestLinks`: pages linked with at least two neighbors, each neighbor and each candidate weighted down by its own number of links, summaries, guides and prompts left out, top six with "via" names); plain-link groups are `<details>`, folded past eight. `.cm-sub` inside the atlas and the Lens is now muted and small. Commands: **Open the atlas** (`Alt+M`, id unchanged), **Open the Lens** (`Alt+L`), and the new **Show this page in the atlas**.
