The history of every version of the Coppermind's rules (`_AGENTS.md` and the files in `SCHEMAS/`), newest first. Lines before 7.0 name sections of the single `SCHEMA.md` the rules used to be, and they record what was true then. The current version is in the `version` property of [[SCHEMA]]. How changes are made: [[SCHEMA - Changes]].

## Changelog

- **8.10 (2026-11-22):** Nicrosil keeps the index up to date, so agents no longer edit `_index.md`. `_AGENTS.md` (Permissions, Bookkeeping, Saving tokens) now says to leave it alone and to write a good `> [!summary]` callout, which is what the index shows. `SCHEMA - Index and Log` (The index) describes the automatic upkeep, the **Update the index now** command, the **Keep the index up to date** setting and the 20-removal / 100-addition safety limit; `SCHEMA - Ingest` (Commit step) and `SCHEMA - Query` (File back) no longer have the agent do index work; `SCHEMA` says Nicrosil maintains the index. Health checks still compare the index with the pages.
- **8.9 (2026-11-22):** `The Tinmind/`, my own class notes and their dashboard, is named in the rules. `_AGENTS.md` (Permissions) gains a row: agents read one file there only when I name it, may build the dashboard page and empty course files when I ask, and otherwise don't open, list, search, quote, count or mention anything in it. `SCHEMA` lists the folder in its layout and among the files that are not wiki pages, and `SCHEMA - Health Check` puts it outside every check, like `Ingestion/Raw/`. The check script skips it. Nothing else about the rules changed.
- **8.8 (2026-11-22):** Triage loses its Done section. `SCHEMA - Ingest` (Commit step and Triage) now has the agent delete a batch from Triage once it is fully ingested, whether or not its pages are verified; a batch with part deferred keeps only that part, marked `[~]`. `SCHEMA - Health Check` (the Triage check) matches. `Ingestion/Triage.md` says the same in its key. Nothing else about the rules changed.
- **8.7 (2026-11-22):** Agents no longer suggest commit messages. `_AGENTS.md` drops the **Commit** line from the log entry format and the commit-message rule from the bookkeeping rules. `SCHEMA - Index and Log` drops the commit message from tool entries, the intro and the Version control section, and `SCHEMA - Ingest` (Commit step) no longer has the agent suggest one. The setup guide `Setting Up Git for the Coppermind` no longer tells me to use a suggested message. Earlier log entries keep their commit lines, because past entries are never rewritten.
- **8.6 (2026-11-21):** The wiki no longer has a showcase goal. `SCHEMA` (Purpose and scope) drops it and now lists two jobs, in the same order: a productivity tool for life, then a record of my developing perspective. The opening paragraph of `SCHEMA` and the first paragraph of `_AGENTS.md` no longer call the wiki a SAIL portfolio. Nothing else about the rules changed.
- **8.5 (2026-11-21):** Quick and standard answers are shorter again: they no longer include a counter-evidence part or a part for Harrison's Perspectives. `SCHEMA - Query` (Every answer) marks both *deep only*, and the Quick, Standard and Deep rows of the Depth table say which parts each depth has. The rule that sources and his views stay apart, and that his views are never presented as fact, still applies at every depth. The question types and filing back are unchanged.
- **8.4 (2026-11-21):** `_AGENTS.md` gains a **How to talk to Harrison** section after the rules for every task: twelve rules for how agents explain things and talk with him in chat (principle first, show how it fits, fixed terms, reasoning over authority, direct answers, concrete examples, naming blind spots, testing ideas, suggesting rather than directing, spelling out the social side, criticizing the work, one task at a time). Wiki pages still follow `SCHEMA - Writing Pages`. Nothing else changed.
- **8.3 (2026-11-21):** Standard-depth answers are shorter. `SCHEMA - Query` (Depth) adds a Length paragraph: a standard answer is concise, with each part of the standard for every answer kept to a line or two, and the long, fully written-out answer is reserved for deep. The Standard and Deep rows of the Depth table say so. The question types, the standard for every answer and filing back are unchanged.
- **8.2 (2026-11-21):** The start file `AGENTS.md` is renamed `_AGENTS.md`, so it is hidden in the file list with the other `_` files. Every rule that names it now says `_AGENTS.md`: `SCHEMA` (the overview, the rule file table, the folder layout), `SCHEMA - Changes`, `SCHEMA - Export`, `SCHEMA - Index and Log` and `SCHEMA - Query`, and its own permissions row.
