The history of every version of the Coppermind's rules (`AGENTS.md` and the files in `SCHEMAS/`), newest first. Lines before 7.0 name sections of the single `SCHEMA.md` the rules used to be, and they record what was true then. The current version is in the `version` property of [[SCHEMA]]. How changes are made: [[SCHEMA - Changes]].

## Changelog

- **7.5 (2026-11-20):** The Schema Changelog is now newest first, and a new line goes at the top, under the `## Changelog` heading. `SCHEMA - Changes` (Nicrosil and other tools) says so; no earlier line was rewritten, only reordered. Nicrosil 2.7.7 adds the Log a schema change line at the top.
- **7.4 (2026-11-20):** The version-history folder is named `_changelogs/`, and the Schema Changelog moved into it from `SCHEMAS/`. `AGENTS.md` (read rule, permissions row, Nicrosil rule): `_version_histories/` and `Nicrosil Version History.md` become `_changelogs/` and `Nicrosil Changelog.md`. `SCHEMA - Changes` (Nicrosil and other tools) and `SCHEMA - Index and Log` (The log): the same wording. `SCHEMA` (rule file table, folder layout, files that are not wiki pages, the other files): the new folder name, and the changelog is no longer listed inside `SCHEMAS/`. Nicrosil 2.7.4 makes the **Log a schema change** button find the file in its new place.
- **7.3 (2026-11-20):** Version histories moved out of the guides. `AGENTS.md`: agents don't read `_version_histories/` unless adding a line or asked, a new permissions row for the folder, and the Nicrosil rule puts the version-history line in `_version_histories/Nicrosil Version History.md` instead of the guide. `SCHEMA - Changes` (Nicrosil and other tools): the line goes there, and look-and-feel detail belongs in the history, not the guide's body. `SCHEMA - Index and Log` (The log): tool entries point to that file. `SCHEMA` (folder layout, files that are not wiki pages, the other files): the new folder.
- **7.2 (2026-11-20):** The index is easier to browse. `SCHEMA - Index and Log` (The index): Concepts and Glossary are split by first letter under `### A` headings (`### 0–9` for digits), a **Jump to** line under the total links to each type, and `index.md` has a `coppermind-index` CSS class for its look; the line format is unchanged. `AGENTS.md` (Bookkeeping, Index): the index rule now names the letter headings and says the Jump to links change with the counts. Nicrosil 2.7.2 keeps both right when a page is rejected.
- **7.1 (2026-11-19):** Nicrosil changes now always get their bookkeeping. `AGENTS.md`: a new **Nicrosil** rule says any edit to a file in the plugin's folder, even a one-line style tweak, is a tool change, to be done with `SCHEMA - Changes` read first, and the table row for `SCHEMA - Changes` names style tweaks. `SCHEMA - Changes` (Nicrosil and other tools): says every change counts and that the version bump, guide update and `tool` log entry are done in the same edit without being asked. Nicrosil 2.6.1: the guide's update checklist adds the `manifest.json` version and the `tool` log entry.
- **7.0 (2026-11-19):** The schema is split into rule files to save tokens. `AGENTS.md` is now the only file every agent reads: it holds scope, drafts only, permissions, voices, no unsourced claims, the index line and log entry formats, token-saving rules, and a table of which rule file each task needs. `SCHEMA.md` moved to `SCHEMAS/` as the overview, and the rules moved, with their wording kept, to `SCHEMA - Writing Pages` (§3, §4, §5, §6, §8), `SCHEMA - Review` (§7), `SCHEMA - Ingest` (§10 ingest, the Ingest Queue, and the steps of [[Dissect and Ingest a Source]]), `SCHEMA - Query`, `SCHEMA - Health Check` (§10 health check and the report archive), `SCHEMA - Index and Log` (§11, §12), `SCHEMA - Changes` (§14, Tools, the change note on the schema), and `SCHEMA - Export` (§13); this changelog is its own file. New rules: agents never read the whole log and find pages by searching names and aliases instead of reading the index; the log is split by month into `Logs/Log YYYY-MM.md`; a new `tool` operation for changes to `Tools/` and Nicrosil; a health check runs `Tools/health-check/coppermind_check.py` for the mechanical checks and by default reads only pages changed since the last report plus a sample of 20; finished Ingest Queue batches collapse into a Done section. `CLAUDE.md` loads `AGENTS.md`. Nicrosil 2.6.0, the templates, the Health Check Report template, and the pages that linked to the old sections were updated to match. Every rule file is `draft` with a change note until I verify it.
- **6.2 (2026-11-19):** §7 rule 8: a change note may end with a link to the section it changed, `[[#Heading]]`, and Nicrosil 2.4.9 turns such a line into a link that goes to that spot in the page, in the review card and on the Dashboard. Notes without a link still open the page. Status stays `draft` until I verify it again (§7).
- **6.1 (2026-11-19):** Health checks now have a rhythm: one every 14 days, counted from the newest report in `Health Checks/` (§2 and §10), and the Dashboard's health check card in Nicrosil 2.4.8 shows the days since the last one and turns red when one is overdue. §7 rule 8 now says in so many words that it covers `SCHEMA.md` and what the change note and the changelog each do; the agent had been setting the SCHEMA back to `draft` without a note, so its changes did not show in the changed-since-verified list. The §10 health check names `SCHEMA.md` in that check. Status returns to `draft` until I verify it again (§7).
- **6.0 (2026-11-19):** Citations are now footnotes instead of parentheses. §6: rule 1 rewritten with each example shown as a footnote definition; new rule 2 on how footnotes are written (numbered IDs, a `## Footnotes` section at the end of the page, one footnote per source and location, markers after punctuation, markers allowed in callouts and tables, sources that are part of the sentence stay inline links); later rules renumbered; the attribution table and the "Whose view is this?" example put dates in the footnote. §10: the health check also looks for markers without definitions, unused definitions, and parenthetical citations left over. Every wiki page and the two source cards with citations were converted, with wording unchanged; the 62 verified pages went back to `draft` with a `changes_since_verified` note. The page templates, the Health Check Report template, [[Dissect and Ingest a Source]], and Nicrosil 2.4.5 (search snippets skip footnotes) were updated to match. Status returns to `draft` until I verify it again (§7).
- **5.3 (2026-11-19):** Guides are now only about the Coppermind itself. §2: the `Guides/` folder is described as how-to pages about the vault, a new "Guides: about the Coppermind itself" subsection says that a how-to about anything else (a course process or guest-lecture advice) is a workflow, and `Workflows/` is described as holding processes from my courses as well as from running the wiki. §6: the URL-citation exception now refers to guides about the Coppermind's own tools. The `Guide` template summary placeholder was updated to match. Status returns to `draft` until I verify it again (§7).
- **5.2 (2026-11-17):** Verified pages the agent changes now say what changed. §4: new `changes_since_verified` property, a list of one-line notes. §7: new rule 8 and a longer rule 5; the agent adds the note in the same edit that sets the page back to `draft`, and verifying the page deletes it. §10: the health check flags re-reviews without a note. `Review Queue.base` has a "Changed since verified" view, and Nicrosil v0.8.11 deletes the field on Verify, lists these pages first with an R badge, and shows the notes on the card and the Dashboard. Status returns to `draft` until I verify it again (§7).
- **5.1 (2026-11-17):** The index no longer splits each type into Verified and Drafts (§11). Each type is one alphabetical list with a single total, and a change of status no longer changes the index. Nicrosil v0.8.6 was updated to match. Status returns to `draft` until I verify it again (§7).
- **5.0 (2026-11-17):** Typed links reworked after the first health check found 82% of them were `related`, about half of those stored on both pages. §5: three new types (`type_of`, `causes`, `developed_by`), `applies_to` widened to rules that govern something, `supports` and `contradicts` defined for concept pages, and the types listed in the order the agent tries them. New linking rules: store a relationship on the page the sentence starts with and never store the reverse; propose links to verified pages instead of falling back to `related`; "see also" links stay in the page text; every `related` link says why no stronger type fits; links rest on what a source says; "Sources disagree" across two pages becomes a `contradicts` proposal; glossary and concept pages link to each other in the text, not in both pages' properties. §4: the new property names. §10: the health check now reports the typed-link mix. The page templates, the Health Check Report template, and [[Dissect and Ingest a Source]] were updated to match. Status returns to `draft` until I verify it again (§7).
- **4.4 (2026-11-17):** `Find.md` and `Library.base` removed from the vault, and every mention of them removed from the rules (§2, §6, §9, §10, §11, §13). Earlier changelog lines still name them, since they record what was true then. Status returns to `draft` until I verify it again (§7).
- **4.3 (2026-11-17):** The review plugin is now called Nicrosil (§2, §7, §11). The name only changed; nothing about how reviewing works. Status returns to `draft` until I verify it again (§7).

Status returns to `draft` until I verify it again (§7).
